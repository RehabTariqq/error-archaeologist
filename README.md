# Error Archaeologist

A local debugging assistant that remembers programming errors
and retrieves previously solved cases.

## Features

- Save errors and their solutions
- Store debugging cases locally
- List saved cases
- Search for similar errors using text matching

## Technology

- Python
- JSON file storage
- Basic information retrieval

## Run

```bash
python main.py
## Example workflow

1. Start the program.
2. Save an error and its working solution.
3. Search for the error when it appears again.
4. Review the previously saved solution and explanation.
